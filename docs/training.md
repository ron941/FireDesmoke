# Training availability

The 2026-11-16 delivery contains trained weights, model definitions and inference
code. The authors are preparing the corresponding training program separately.
This checkout does not include a training command or claim training reproduction.

The full checkpoint uses Real Smoke Transfer and Semantic Rectification. The
separate FireDesmoke* checkpoint is trained only on the SmokeBench training split.
See [model cards](provenance_model_cards.md) for checkpoint identities.
